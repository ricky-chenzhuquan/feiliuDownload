FAQ

Why is the download so much faster?

Many websites throttle each connection. FeiLiu splits the file into chunks and downloads different parts with up to 64 simultaneous connections, bypassing per-connection limits and saturating your bandwidth.

Does multi-connection work on every site?

It depends on whether the server supports byte ranges (Accept-Ranges). FeiLiu probes this automatically for every task and shows it in the UI; unsupported servers gracefully fall back to a single connection.

Will my download survive an app restart?

Yes. Every chunk's progress is stored on disk in real time. After restarting, click resume (or enable auto-resume) and it continues from the exact byte where it stopped.

When will the iOS version be available?

The iOS app is complete and being prepared for signing and release. It will be available via App Store / TestFlight.

Which video sites are supported for link parsing?

Bilibili (videos, collections, series, bangumi), Douyin (watermark-free), Kuaishou, Xiaohongshu, Weibo, Twitter/X, NetEase Cloud Music (free songs + playlist batch), 82DJ, Bandcamp, Internet Archive, Lanzou Cloud, GitHub Releases, magnets/torrents and generic video pages — paste the link and the real stream is resolved. Aliyun Drive / Baidu Netdisk / CSDN shares are listed with guidance (downloads behind platform login walls). YouTube and other login-gated overseas platforms are on the roadmap.

How does watermark-free downloading work?

For platforms like Douyin, FeiLiu resolves the original stream (playwm → play) instead of the watermarked share file, so saved videos carry no platform watermark. We also respect each site's required headers (Referer etc.) so downloads don't 403.
